List Sync
Schedule and behavior for syncing lists from your connected sources into PublicMetaDB.
Minimum 21600 s (6 h). Default 43200 s (12 h). Scheduled from end of last successful run.
Watch History
Import watched history into PublicMetaDB. The selected source is the only write direction for this rule.
AniList records no watch history — no plays, no per-episode dates. SyncMeta derives episodes from each entry's progress count ("watched 12 of 24") and stamps them all with that entry's completion date, then places them on the right season using the same mapping SIMKL's episode counts use. It writes only episodes PublicMetaDB is missing and can never represent a rewatch. Pick Trakt or SIMKL instead if either tracks the same anime.
Minimum 86400 s (24 h). Only affects automatic history sync.
A normal sync only asks SIMKL for history since the last run, so an episode missed by an interrupted run — or watched before you connected — is never offered again. This reads your whole watched state each time and writes only what PublicMetaDB is missing, which is what fills in the earlier seasons of a long-running show. Costs one extra full read per history sync.
Trakt's history is a play log read forward from the last sync, so episodes watched before you connected — or missed by an interrupted run — never come back. This also reads your complete watched state and writes only the episodes PublicMetaDB is missing, which is what fills in the earlier seasons of a long-running show. Costs one extra full read per history sync.
Resume Progress
Import continue-watching progress. When background sync is on, this refreshes automatically on its own schedule.
Minimum 86400 s (24 h). Only affects automatic resume sync.
